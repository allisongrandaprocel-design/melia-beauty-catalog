# Mélia Beauty Catalog

Single-file online storefront for **Mélia Beauty**, a cosmetics business, with direct WhatsApp checkout integration. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no backend, no build steps.

## About

This project replaces the need for a full e-commerce platform for a small beauty business. Customers browse products directly in the page and complete their purchase through WhatsApp, keeping the whole flow simple and lightweight.

## Features

- 🛍️ Product catalog display
- 💬 One-click purchase via WhatsApp integration
- ⚡ Zero dependencies — pure HTML/CSS/JS
- 📱 No backend or build step required to run or deploy

## How to run it

1. Clone or download this repository
2. Open `catalogo_melia.html` directly in your browser

No installation, server, or build process needed.

## Tech stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Why no framework?

For a small, single-page catalog like this, a plain HTML/CSS/JS approach keeps the project lightweight, easy to host anywhere (even a free static host), and simple to maintain without extra tooling.
